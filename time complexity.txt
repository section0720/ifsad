최악의 시간을 산정하여 문제를 해결하게 됨
최악의 시간 복잡도를 표기하는 방법을 빅-오(big-O)표기법이라 하며 데이터 크기가 N일 때, O(N)의 방식으로 표기한다.
어떤 문제를 풀었을 때, 어떠한 알고리즘으로 풀어야 시간을 초과하지 않는지에 대해서 아는 방법을 아래 서술한다.
컴퓨터는 1초에 100,000,000개의 데이터를 처리할 수 있고,
문제는 보통 시간 제한을 s초라고 주고 데이터의 범위를 1<= N <= M의 형식으로 준다
빅-오 표기법은 최악의 연산 속도를 산정하는 시간복잡도 표기라고 하였기에 자신이 사용할 알고리즘에 데이터의 최대값을 대입하여 나온 값이 100,000,000*s보다 작으면 해당 알고리즘은 적합하고 반대라면 부적합하다
백준 2750번을 예로 들자면
이 문제는 N개의 수를 오름차순 정렬하는 문제이다. N의 크기가 1<= N <= 1,000,000이고 시간제한이 2초이다
만약 이를 O(n^2)의 알고리즘인 버블 정렬로 풀게 되면 (1,000,000^2) = 1,000,000,000,000 > 2,000,000,000이기 때문에 부적합하다.
즉 이문제는 적어도 O(n)정도의 알고리즘으로 풀어야한다.
그런식으로 어떤 알고리즘으로 문제를 풀어야 할지는 (빅-오 표기법의 대입값)과 (시간 제한 초*100,000,000)를 비교하면 된다.
